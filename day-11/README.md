# 📇 Contact Manager

This is a small Python program that helps you  **save and manage contacts** .

You can add people, edit them, find them, and delete them.

---

## 💡 What it does

With this program, you can:

* Add a new contact (name, phone, email, group)
* Edit or change a contact
* Find a contact by name
* Show all contacts or by group
* Delete a contact
* See how many contacts you have

---

## 🧠 What I learned

I made this project to practice:

* Using **Python classes**
* Working with **dictionaries and lists**
* Using **dataclasses**
* Writing a simple **menu in the terminal**
