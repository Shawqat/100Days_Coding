1. Create a file called `calculator.py`.
2. Write a program with these functions:
   * `add(a, b)`: returns the sum
   * `subtract(a, b)`: returns the difference
   * `multiply(a, b)`: returns the product
   * `divide(a, b)`: returns the quotient (handle division by zero with error handling)
3. Ask the user to enter two numbers and choose an operation.
4. Print the result using the appropriate function.
