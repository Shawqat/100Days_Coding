# Starting learning - Front end development.

* start learning html

### Concepts Covered Today:

1. **HTML Document Structure** : `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
2. **Semantic HTML** : `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` it's tags that describe it's purpose.
3. **Basic Tags** : `<h1>-<h6>`, `<p>`, `<ul>`, `<li>`, `<img>`, `<form>`
4. **Attributes** : `id`, `class`, `src`, `alt`, `href`
